# Canopy 简体中文本地化包

本发行包基于 ForestOfLight 的 Canopy v1.6.3。原作者为 ForestOfLight，中文本地化维护者为相安（3199912548@qq.com），按随包 MIT 许可证分发。完整项目说明、源码及更新记录见 <https://github.com/xiangan666/Canopy>。

用《我的世界》国际基岩版打开 `.mcaddon`，在世界设置中同时启用行为包和资源包，并使用简体中文。清单要求最低引擎版本为 `[1, 26, 60]`；脚本依赖多个 Beta API，需与这些 API 相匹配的客户端或服务端，并启用相应实验选项。最低版本号本身不能保证任意后续稳定版可运行。

进入测试世界后输入 `./help` 检查帮助输出；`./` 是 Canopy 的默认聊天命令前缀。升级前备份世界、行为包和资源包，升级时同时替换两个包。遇到错误时保留内容日志，并在项目 Issues 中附上两个包的版本、游戏版本及复现步骤。

本包的头部 UUID 与上游一致，用于保持已有世界引用。因此请勿与相同 UUID 的上游版本同时启用。回退时恢复世界备份和上一版的两个包；仅替换脚本不能保证撤销世界数据变化。
