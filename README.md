# Canopy 简体中文本地化版

Canopy 是一个面向技术生存、红石测试和服务器运维的《我的世界》国际基岩版扩展包。本项目基于 Canopy v1.6.3，完整维护简体中文语言资源，并将游戏内命令、规则提示、信息显示、实体调试栏及运行时反馈中的玩家可见文本本地化。

## 功能范围

- ./help 指令帮助，以及 Canopy 规则和 InfoDisplay 信息显示规则。
- 区域方块分析、距离和坐标工具、区块边界、光照和红石信号显示。
- 漏斗计数器、漏斗生成器、刷怪跟踪、实体密度和生命周期追踪。
- 模拟玩家管理、物品栏查看、快捷填充容器、窥视容器和耐久度提示。
- TNT、矿车、末影珍珠、活塞、爆炸、碰撞箱等技术向规则。
- 简体中文语言包覆盖行为包和资源包中使用的全部本地化键。
- 游戏内硬编码的玩家可见输出（包括维度名称、实体调试字段和追踪统计）也已本地化。

## 安装

1. 从 Releases 下载 Canopy-v1.6.3-zh_CN.mcaddon。
2. 用《我的世界》国际基岩版打开该文件，等待导入完成。
3. 在世界设置中同时启用 Canopy 行为包和资源包，并将资源包置于行为包对应的活动包列表中。
4. 使用与清单兼容的游戏版本，清单最低版本为 1.26.60。如果客户端提示需要实验性脚本或 Beta API，请按客户端提示启用。
5. 进入世界后输入 ./help 查看 Canopy 指令；原版斜杠指令使用游戏内 /help 查看。

本项目只提供本地化和可维护的源码目录，不会覆盖上游原始 .mcaddon 文件。

## 从源码构建

需要 Windows PowerShell 和 Node.js（仅用于语法检查）。在项目根目录运行：

    .\tools\build.ps1

构建结果位于 dist/Canopy-v1.6.3-zh_CN.mcaddon。脚本会在打包前检查：

- 行为包和资源包的 manifest.json 是否为有效 JSON；
- texts 目录中的语言键是否全部被 zh_CN.lang 覆盖；
- 语言文件是否存在重复键；
- 所有 JavaScript 文件能否通过 Node.js 语法检查；
- 压缩包内是否只包含 Canopy[BP]/ 和 Canopy[RP]/ 两个顶层目录。

脚本检查不替代在目标《我的世界》客户端中的实际运行测试。

## 项目结构

    source/
      Canopy[BP]/       行为包、脚本和规则
      Canopy[RP]/       资源包、界面和语言文件
    tools/
      build.ps1         校验并生成 .mcaddon
    dist/               构建输出（默认被 Git 忽略）

## 本地化约定

- 指令名、规则 ID、实体 ID、物品 ID、占位符（例如 %1、%s）和颜色代码保持不变。
- 面向玩家的提示使用简体中文；技术名词在首次出现时保留必要的英文标识。
- en_US.lang 等上游语言文件保留，便于比对和继续同步上游更新。
- 上游代码和许可证声明保持原作者署名；本项目的本地化维护者为相安。
